수집 현황

현재 코드가 무엇을 · 언제 · 어디서 받아 어느 테이블에 저장하는지 정리한다. 실행 시각은 한국 시간(KST), 저장 시각은 UTC가 기준이다.

범위. 이 문서는 가격·금리·거시·수급·포지셔닝과 거래일 캘린더처럼 수치로 저장되는 데이터만 다룬다. 뉴스·공시 원문 수집과 LLM 평가는 문서 수집과 평가 흐름에 있다. 아래 항목 수와 일정은 2026-08-25의 코드 정의 기준이며 DB 행 수는 적지 않는다.

가격 심볼과 제공처

Yahoo — 26심볼

QuoteSymbol 한 곳이 저장 심볼, Yahoo 좌표, 표시 이름, 저장할 자산 종류를 묶는다. 분봉은 최근 15분을 기본으로 저장하고, 일봉은 같은 목록을 기본 10년 범위로 받는다.

삼성전자·SK하이닉스 1분봉

국내 종목은 005930(삼성전자)와 000660(SK하이닉스)을 KRX와 NXT로 나눠 저장한다. 통합 시세 UN은 쓰지 않는다.

단계시간역할저장 규칙
KIS WebSocket연결 창 평일 07:50–20:10 H0STCNT0(KRX)·H0NXCNT0(NXT) 체결을 1분봉으로 집계 ingest_method=websocket, is_final=false
장중 REST 보정평일 매시 05·35분, 08–19시 최근 한 응답을 다시 받아 WebSocket 누락·부분봉을 보정 is_final=true; 늦은 WebSocket은 확정봉을 덮지 못함
마감 REST 확정평일 20:05 KRX 정규장과 NXT 프리·주간·애프터를 거래일 전체로 다시 수집 stock_bar 자연키로 최종 upsert

KIS_ENABLE_NXT_WEBSOCKET과 KIS_ENABLE_NXT_REST는 NXT만 떼는 운영 손잡이다. 둘 다 비어 있으면 켜지고, 알 수 없는 값은 시작 또는 DAG 실행을 실패시킨다.

저장과 계보

데이터 모양자연키비고
자산 종류별 분봉(provider, symbol, bar_at) index_bar·fx_bar 등으로 분리. quote_bar는 자산별 테이블과 미국 ADR을 합친 호환 뷰이며 KRX/NXT 종목은 제외
자산 종류별 일봉(provider, symbol, business_date) index_daily·fx_daily 등으로 분리. quote_daily도 같은 범위의 호환 뷰
개별 종목 분봉(provider, stock_code, exchange, bar_at) 거래소 축과 is_final이 있어 stock_bar에 별도 저장
지표 관측값(provider, series_id, observation_date) 제공처가 같은 ID를 써도 충돌하지 않음
모든 수집은 source_record로 이어진다. 고빈도 폴링은 심볼마다가 아니라 실행 1회를 계보 1건으로 묶고 원본 payload를 남기지 않는다. 심볼별 성공·실패, 조회 창, 최신 봉 시각은 metadata에 기록한다. 봉이 0건이어도 정상 응답이면 성공 계보를 남겨 “조회했지만 휴장”과 “아직 조회하지 않음”을 구분한다.

운영 경계

  • Yahoo v8 chart는 비공식 API이고 1분봉 보관 기간은 약 30일이다. HTTP 429와 제공처 변경 가능성을 운영 범위로 본다.
  • USDCNH는 Yahoo가 긴 일봉 이력을 주지 않아 운영 시작 뒤 데이터가 중심이다.
  • KIS 국내 지수선물 REST는 정규장만 제공한다. 야간 파생 시세는 현재 수집하지 않는다.
  • KIS 미국 현물지수 마감 수집은 최근 102봉만 주며 날짜 커서가 없어 백필할 수 없다.
  • 거래일 캘린더가 아직 없으면 수집을 계속한다. 모른다는 이유로 실제 거래일 데이터를 버리지 않기 위해서다.
  • 행 수는 계속 바뀌므로 이 문서에 고정하지 않는다. 최신성·봉 수는 Grafana 대시보드에서 확인한다.
